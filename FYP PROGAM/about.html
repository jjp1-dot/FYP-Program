📖 About FindYourProgram

Web-Based College Program & School Recommendation System

🎓 Project Overview

FYP - Find Your Program is a web-based tool developed to help students identify suitable college programs based on their interests, skills, and personal strengths. The system uses structured assessments to generate personalized recommendations and provides administrators with a dashboard to manage content, schools, and analytics.

Subject: Software Engineering 1  |  Date: April 8, 2026

📌 Background

Many students struggle to choose a college program that aligns with their interests and career goals. Traditional methods (self-assessment, peer advice, limited counseling) are often subjective and lack data‑driven guidance. This project automates the process, providing personalized recommendations and giving administrators tools to manage content and analyze trends.

🎯 Objectives

  • Develop an interactive assessment that evaluates student interests through structured questions.
  • Provide personalized college program recommendations based on assessment responses.
  • Create an admin dashboard to manage questions, schools, programs, and content.
  • Generate analytical insights to help administrators understand student trends and program demand.

📐 Scope & Limitations

Scope: Students can take an assessment, receive program recommendations, and view top schools. Administrators can manage all content and view analytics.

Limitations: The system does not guarantee admission, replace professional counseling, or include AI/ML. It is web‑only and relies on honest student responses.

🔄 Development Methodology

Agile Development Model – chosen for flexibility and iterative delivery. The system was built in small increments (assessment module, recommendation logic, admin dashboard, CMS, analytics), tested early, and refined based on feedback.

Phases: Planning → Analysis → Design → Implementation → Testing.

✅ Conclusion & Future Work

The system successfully meets its objectives: students receive structured guidance, and administrators have a powerful management dashboard. Future improvements could include a mobile app, machine learning for better recommendations, real‑time counselor chat, and career tracking.
